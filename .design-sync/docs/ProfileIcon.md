The Perfil tab glyph: head and shoulders.

Same API as every tab icon — one optional `className` replacing the 21×21
default, `fill: currentColor`, `aria-hidden`.

```tsx
<span className="text-fg-dim">
  <ProfileIcon />
</span>
```

For a member's actual face, use `Avatar`; this is the tab, not the person.
